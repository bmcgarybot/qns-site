# 🐌 QNS Website Editing Guide
### For Big Dog — no code skills needed

---

## How to Edit

1. Go to **github.com/bmcgarybot/qns-site**
2. Click the file you want to edit (usually `index.html` or `technology.html`)
3. Click the **pencil icon** ✏️ (top right of the file)
4. Find the section below → change the text between the `>` and `<` tags
5. Click **"Commit changes"** (green button)
6. Site updates in ~1 minute

**Golden rule:** Only change the words between `>` and `<`. Don't touch anything that looks like code.

Example: `<h1>Old Title</h1>` → `<h1>New Title</h1>`

## ⚠️ Don't Touch

- Anything inside `<style>` tags (that's the design)
- Anything inside `<script>` tags (that's functionality)
- Class names like `class="hero"` or `class="section-dark"`
- The `<svg>` blocks (those are the app icons)
- Links that start with `#` (those are navigation anchors)

## 💡 Tips

- **Use Ctrl+F** (or Cmd+F on Mac) to search for text on the page
- **Change text only** — the words between `>` and `<`
- **Preview before committing** — GitHub shows you what changed in green/red
- **Broke something?** Go to the file's history (clock icon) and revert to the previous version
- **Want to change photos?** Upload new images to the `img/` folder, then update the filename in the `src="./img/filename.jpg"` part
